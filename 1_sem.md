# БЛОЧНЫЕ ЭЛЕМЕНТЫ
ПРАВИЛА БЛОЧНЫХ ЭЛЕМЕНТОВ:
1) По умолчанию, блочные элементы выстраиваются друг за другом по вертикали (друг под другом) и занимают всю возможную ширину экаран (зависит от размера экрана).
2) По умолчанию, высота блочных элементов автоматически увеличивается от количество и размеров содержимого в них.

# СТРОЧНЫЕ ЭЛЕМЕНТЫ

1) Строчные элементы по умолчанию занимают ровно столько ширины, сколько нужно для их содержимого, и не начинают новую строку.

# АТРИБУТЫ ТЕГОВ
HTML-атрибуты это специальные слова, которые управляют поведением HTML-элемента. Они добавляют дополнительную функциональность, либо меняют поведение элемента по умолчанию. Атрибуты элемента выражаются внутри начального тега элемента.
Атрибут имеет имя и значение. Имена атрибутов должны состоять из одного или нескольких символов, кроме управляющих, таких как пробел, ", ', >, / и =. Имена и значения атрибутов не чувствительны к регистру, но, тем не менее, рекомендуется набирать их в нижнем регистре.

class - CSS-класс, который позволяет идентифецировать элемент, задать свойства конкретному элементу или ряду элементов с таким же названием.
id - (та же суть что и у class), позволяет идентифецировать элемент (чаще всего применятся для привязки JS-скриптов)
href - указывает на адрес ссылки (внешнеий или внутренний). Чаще всего применяется к тегу <a>
src - путь к файлу изображения (внутренний или внешний) - Чаще всего применяется к тегам: <script>, <img>.
alt - текстовое описание изображения. Применяется для <img>. Необходим для поисковых систем.
title - дополнителная всплывающая подсказка.
name - имя поля при отправке формы. Применяется для <input>.
value - позволяет получить значение поля <input>
type - тип кнопки или поля ввода.
placeholder - подсказка внутри поля ввода например <input>.
required - проверка заполненности поля ввода <input>.
disabled - отключенный элемент.
checked - выбранным checkbox/radio
... Кастомные атрибуты

# КАСКАДНЫЕ ТАБЛИЦЫ СТИЛЕЙ (CSS)
CSS (Cascading Style Sheets) — язык таблиц стилей, который позволяет прикреплять стиль (например, шрифты и цвет) к структурированным документам (например, документам HTML и приложениям XML).

Обычно CSS-стили используются для создания и изменения стиля элементов веб-страниц и пользовательских интерфейсов, написанных на языках HTML и XHTML, но также могут быть применены к любому виду XML-документа, в том числе XML, SVG и XUL.

Пример:
селектор {
    свойство: значение;
    свойство: значение;
}

селектор {
    свойство: значение;
}
